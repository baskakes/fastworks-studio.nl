# fastworks-studio.nl

Website van FastWorks, de filmstudio van Bas Kakes (Dordrecht).

- Statische site zonder build-stap: alles staat in `docs/` (HTML, CSS, JS, beelden en fonts).
- Gehost via GitHub Pages: *Settings → Pages → Deploy from a branch → `main` / `docs`*.
- Domein `www.fastworks-studio.nl` (zie `docs/CNAME`); DNS bij Hostnet wijst naar GitHub Pages.

## Aanpassen

Teksten staan in `docs/index.html`. Beelden staan in `docs/img/` (webp, max. ~1920 px breed).
Een wijziging op `main` staat binnen een paar minuten live.
